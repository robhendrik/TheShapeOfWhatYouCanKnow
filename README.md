# The Shape of What You Can Know

Companion repository for the article **[Quantum Mechanics Should Make This More Complicated. It Doesn't.](https://armchairquantumphysicist.com/2026/10/13/quantum-mechanics-should-make-this-more-complicated-it-doesnt/)** on [The Armchair Quantum Physicist](https://armchairquantumphysicist.com/).

## About

A simple guessing game produces an increasingly complicated classical strategy space. Add quantum mechanics, and something unexpected happens: the many-faced polytope collapses onto a sphere.

This project explores why quantum mechanics gives Alice and Bob more possibilities while making the geometry simpler. The article explains the physics and the geometry; this repository holds the material behind it, so you can explore the details yourself.
